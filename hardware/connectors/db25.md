# DB25

## 25-Pin Connector Pinout

| Pin | Function      | Pin | Function      |
|----:|---------------|----:|---------------|
|  01 | GND           | 14  | not connected |
|  02 | +5V           | 15  | not connected |
|  03 | GND           | 16  | not connected |
|  04 | not function  | 17  | DI8           |
|  05 | DI7           | 18  | DI6           |
|  06 | DI5           | 19  | DI4           |
|  07 | DI3           | 20  | DI2           |
|  08 | DI1           | 21  | not connected |
|  09 | DO8           | 22  | DO7           |
|  10 | DO6           | 23  | DO5           |
|  11 | DO4           | 24  | DO3           |
|  12 | DO2           | 25  | DO1           |
|  13 | +5V           |     |               |

## Legend
- **GND**: Ground
- **+5V**: +5 Volts power supply
- **DE** - 'Digitale Eingang' Digital Input
- **DA** - 'Digitale Ausgang' Digital Output
- **nicht belegt**: Not connected (NC)
- **ohne Funktion**: No function (NF)

## Teachbox keys-to-DB25 mapping 

```
  [DB25 PIN]   [DESTINATION / ROUTING]
  
   Pin 3   -----> STOP (1)
   Pin 4   -----> STOP (3)
   Pin 5   -----> DEL, 8, 9, +, -, NOP, ERR, ENT
   Pin 17  -----> MARK, GOTO, IF, OUT, TIM, INS, POS, RUN
   Pin 18  -----> 7, 4, 5, 6, 1, 2, 3, 0
```
