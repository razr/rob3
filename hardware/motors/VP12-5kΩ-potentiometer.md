# 5kΩ VP12 Japanese precision servo-feedback potentiometer

## Channel 1

```
                (  [Shaft]  )
                  +-------+
                  |       |  <- Potentiometer Body
                  +-------+
                  |   |   |
                  1   2   3
                  ↓   ↓   ↓
  connector pins: p4  p2  p1
                 GND  5V  pin 25 ADC
```
