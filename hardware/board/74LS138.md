# 74LS138

The 74LS138 is a 3-to-8 decoder used to generate the board's chip-select signals for memory and peripheral devices.

## Pinout

```text
                       TOP VIEW
                     +-----U-----+
      A (LSB) input ─| 1      16 |── VCC (+5V)
       B input      ─| 2      15 |── Y0 (active LOW)
       C input      ─| 3      14 |── Y1 (active LOW)
   G2A (active LOW) ─| 4      13 |── Y2 (active LOW)
   G2B (active LOW) ─| 5      12 |── Y3 (active LOW)
   G1 (active HIGH) ─| 6      11 |── Y4 (active LOW)
    Y7 (active LOW) ─| 7      10 |── Y5 (active LOW)
       GND          ─| 8       9 |── Y6 (active LOW)
                     +-----------+
```

## Board connections

```text
                              +-----U-----+
    pins 1, 11 tied together ─| 1      16 | +5V
                EPROM pin 23 ─| 2      15 | GND
                  SRAM pin 2 ─| 3      14 | 8031 pin 27
                          NC ─| 4      13 | 74HC14 pin 1
         74HC14 pins 4 and 5 ─| 5      12 | EPROM pin 20
                  8255 pin 6 ─| 6      11 | pins 1, 11 tied together
                  ADC pin 22 ─| 7      10 | NC
                         GND ─| 8       9 | NC
                              +-----------+
```

## Notes

- The active-low outputs match the board's memory selection scheme.
- It is the main address decoder for selecting EPROM, SRAM, and peripheral interfaces.

## Reverse-engineering relevance

This decoder defines the board's memory map. The 8031 binary is effectively a sequence of address writes and decode events that select different blocks of the board.

For firmware analysis, the key question is not only which IC is connected, but which output line is active for a given address. That line tells you which device the program is addressing at any moment, and therefore which code, data, or control register is being touched.
