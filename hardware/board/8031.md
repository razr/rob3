# 8031

The Intel 8031 is the controller at the center of the board. It addresses memory, drives the decoder logic, and manages the external I/O and interrupt-driven control loops.

## Notes

- Port 0 is the address/data bus to the external memory devices.
- Port 2 and the control pins select and drive the decoder, EPROM, SRAM, and I/O blocks.
- The 8031 is the system controller for all ICs on this board.

### Full control/address nets (reciprocity reference)

The pinout box above lists the primary connections; the complete shared nets are:

- **pin 16 (/WR)**: ADC pin 19, 8255 pin 36, SRAM pin 27
- **pin 17 (/RD)**: 8255 pin 5, ADC pin 21, 74HC14 pin 12
- **pin 21 (A8)**: EPROM pin 25, SRAM pin 25, ADC pin 20, 8255 pin 9

## Reverse-engineering relevance

This 8031 page is the key anchor for later binary analysis because the firmware traces are organized around the external bus architecture:

- `P0` carries `D0`-`D7` and the lower address byte in alternate phases.
- `P2` carries `A8`-`A15` for the upper address lines.
- `ALE` marks the moment when the lower address byte is latched by `74HC373`.
- `PSEN` selects the EPROM program read path.
- `RD` and `WR` are used for SRAM and 8255 I/O cycles.
- `74LS138` and `74HC373` are the hardware translation layer that converts the CPU address into active chip-selects.

When reverse-engineering the binary, treat the program as a memory-mapped control program for a board with a decoded external device map. The CPU instructions are less important than the address windows, chip selects, and data-handling patterns that are visible on the bus.

## 2 Register Banks

In the Intel 8031/8051 architecture, there are exactly 4 independent Register Banks.

Each bank contains 8 general-purpose working registers, named **R0 through R7**. They live in the very lowest part of the internal RAM (addresses 00h to 1Fh).Here is the breakdown of how they are mapped in memory:
- Register Bank 0: RAM addresses 00h to 07h (Default at boot)
- Register Bank 1: RAM addresses 08h to 0Fh
- Register Bank 2: RAM addresses 10h to 17h
- Register Bank 3: RAM addresses 18h to 1Fh

In early microcontrollers, memory operations were slow. If an interrupt (like your motor step encoder pulse on _INT1) occurs completely at random, the CPU must freeze its main program and handle the interrupt instantly [source: 1].However, the main program is likely using registers R0–R7 to calculate movements. If the interrupt routine also uses R0–R7, it will overwrite and corrupt the main program's data.

Inside the `PSW` register (address `D0h`), `Bit 3` is `RS0` and `Bit 4` is `RS1`. The hardware decodes them like a binary switch:

| `RS1 (0D0h.4)` | `RS0 (0D0h.3)` | Selected Active Workspace |
| :--- | :--- | :--- |
| 0 | 0 | Register Bank 0 (Addresses `00h`-`07h`) |
| 0 | 1 | Register Bank 1 (Addresses `08h`-`0Fh`) ← Your code sets this! |
| 1 | 0 | Register Bank 2 (Addresses `10h`-`17h`) |
| 1 | 1 | Register Bank 3 (Addresses `18h`-`1Fh`) |
