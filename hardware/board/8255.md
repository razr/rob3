# 8255 PPI

The 8255 is the programmable I/O block that expands the 8031 with three 8-bit ports and flexible mode control for the motor, ADC, and external connector wiring.

## Notes

- `L293 #4` is a placeholder in the connection diagram; no fourth L293 is soldered on the board. Its pins are marked `(NP)` (not populated); the corresponding 8255 Port B lines (pins 14–17) are routed but unused.
- Pin 9 (A0) also ties to the A8 address net: 8031 pin 21, EPROM pin 25, SRAM pin 25, ADC pin 20.
- Port A and Port C are the main motor control buses for the L293 drivers.
- Port B and the control lines are used for external interface and decoder coordination.
- The chip is configured as the system's programmable I/O gateway between the 8031 and the board peripherals.

## Reverse-engineering relevance

The 8255 is one of the easiest places to map firmware behavior to physical robot motion because it exposes board-level state in a stable, register-like structure.

When reverse-engineering the binary, the following pattern matters:

- write to the Port A / Port C control registers to change motor direction or enable bits;
- read from Port B or selected control/status lines to sample sensor feedback;
- use the 8031's memory writes to observe which lines are being driven at each execution stage.

The 8255 therefore represents the clearest boundary between raw CPU instructions and board-level robot actions.
During the system's initialization phase, the program deliberately assigns hardware register addresses specifically mapped to an 8255 parallel port configuration [source: 1]:

```asm
jump_01A5:
	mov 83h, #50h	; Sets DPH = 50h
	mov R1, #4Eh	; Sets R1 to 4Eh
	sjmp jump_01B9  ; Jumps into the active I/O operation
```

- The 8255 Memory Map Base: By forcing DPH = 50H, the data pointer targets the memory range 5000H through 5003H. In vintage 8031 address decoding logic, this block is standard for a memory-mapped 8255 PPI.

## 2. Standard 8255 Chip Address Decoding

Immediately after assigning the data pointer, the code loops through the sequential byte layout that matches the architecture of the 8255 registers:

- 5000H (DPH = 50H): Accesses Port A of the 8255 chip.
- 5200H (DPH = 52H): Later in the loop (jump_01B4), the code alters DPH to 52H. This maps precisely to Port C or the Control Word Register depending on whether your hardware address decoding lines shift the lower pins (A0, A1) to select register functions.

## 3. Clear and Write Loops on the I/O Registers

We can watch the processor actively write state telemetry directly out to the peripheral ports using standard external memory commands:

```asm
	mov 83h, #50h	; Targets Port A (Address 5000h)
	mov A, 4Eh
	movx @DPTR, A   ; PHYSICALLY SENDS RAM DATA OUT THROUGH THE 8255 PINS
	
	mov 83h, #52h	; Targets Control/Port C (Address 5200h)
	mov A, 4Fh
	movx @DPTR, A   ; Update 8255 mode control register configuration
```

- What this does: The MOVX @DPTR, A instruction triggers the 8031's external memory write cycle (WR line). Since your program specifically shifts between pages 50H and 52H, it is communicating directly with the 8255 parallel channels to output telemetry or read active data bytes.
